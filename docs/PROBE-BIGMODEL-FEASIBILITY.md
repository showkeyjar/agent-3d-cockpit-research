## ★ 实测裁决（2026-11-19，推翻下文 §0 的「有条件可行」）

按 §4 参数实测后，**隔离路线行不通**，两条子路径都堵死：

| 尝试 | 命令关键参数 | 结果 |
|---|---|---|
| 纯 CPU | `-ngl 0 -c 256 --no-warmup -t 4` + `EIE_NO_PREFETCH=1` | 加载 ~92s 后崩溃 `code=3221226505` (0xC0000409 STATUS_STACK_BUFFER_OVERRUN)，卡在 threadpool init 后的计算图构建；**无错误日志** |

| 少量上 GPU | `-ngl 8` | 6s 内 `vk::Queue::submit: ErrorOutOfDeviceMemory`——GPU 显存已被 8083 主力占满 |

**根因判断**：`build-probe` 二进制（clang-cl 编译的独立副本）与 `build-server` 主力二进制

- `-ngl 0`：CPU 后端对 qwen3next 的 Gated DeltaNet recurrent 路径栈溢出（日志见 288MB S buffer）；
- `-ngl>0`：与主力抢 GPU 显存，直接 OOM。

而 8083 主力二进制能稳定跑同一个 36GB 模型，但它没打 expert-stats 补丁、拿不到路由。

**因此**：在「不动 8083」约束下，**拿不到 512 专家真数据**。唯一可行路径是给 8083 打补丁并重启
（违背约束，且 36GB 加载 + 看门狗干预风险高）。§1–§7 保留为评估推理过程，但其 §0 结论已被本裁决覆盖。

**诚实边界**：8083 全程 health=200、`/experts` 仍 404（未受影响）；探针服务全部终止；
端口 8091–8096 已清理（注：8095 被无关的 zen-gate 服务占用，曾造成一次 health 假阳性，已识别）。

## 0. 结论摘要

**有条件可行。** 用 `-ngl 0`（纯 CPU）+ 小上下文（`c=512`）的隔离实例，权重走与主力共享的

主线的 `internal_state` 仍恒为 `unavailable`（8083 无 `/experts`）。要真正上 3D 编码，

## 2. 关键洞察：mmap 页缓存共享

「36 GB 模型装不下两份」是错的直觉。两个进程 mmap **同一份 GGUF 文件**时，
Windows 页缓存只保留一份物理页，两个进程共享。因此：

- **权重内存增量 ≈ 0**（若主力已热缓存）或按需调入（首次访问慢），不会 2×36 GB；
- **真正的增量开销**是每实例独立的两块：① KV cache（正比于 `ctx`）；② 计算图激活 buffer；
- 所以低内存的关键是**砍 `ctx`**（32768 → 512，缩小 64×）和**不 offload**（`-ngl 0`）。

[静态确认] `eie.patch` 的 `EIE_NO_PREFETCH=1` 已在源码 `llama-model-loader.cpp:1427`：
关闭加载期整文件 prefault，改为按需缺页，避免与 Vulkan 抢物理页——这正是低内存路径需要的。

## 4. 建议的低内存加载参数（未执行）

```bash
cd /d/tools/llama-probe-src/build-probe/bin
EIE_NO_PREFETCH=1 ./llama-server.exe \
  -m /d/tools/llama.cpp/models/Qwen3-Coder-Next-Q3_K_M.gguf \
  -ngl 0 -c 512 --no-warmup -t 4 \
  --host 127.0.0.1 --port 8091 -a probe-big --expert-stats
```

设计理由：

- `-ngl 0`：不分配 Vulkan GPU buffer，避开与主力抢显存（这是最大冲突点）；
- `-c 512`：KV cache 缩到主力的 1/64，指纹采集只需短输出，够用；
- `--no-warmup` + `EIE_NO_PREFETCH=1`：加载期不 prefault，避免抢页拖慢主力；
- `-t 4`：16 核机器上给主力 `-t 8` 留足余量；
- 独立端口 8091：看门狗只探活 8083，不干预。

**吞吐预期** [推算]：80B MoE（3B 激活）纯 CPU，逐 token 要从 36 GB 中随机取 10 个专家权重，
首次访问缺页多；估计 2–10 tok/s。跑 4 个 prompt × 80 token 约几分钟——离线实验可接受。

**方法论教训**：判"某视觉元素是装饰"之前，必须先查它是不是判据载体或实验自变量——外观像噪音 ≠ 可删。本清单初版正是栽在"用眼睛判断可理解性"，与用户批评的"没真正思考就发问卷"是同一类错误。

**★ 二次更正（GPT 评审 #3，v0.9.55）——保留 ≠ 效果已验证**：上面表格写的"实验依据"严格说只是"**装置/判据存在**"（F3.6/F3.7 的显示·隐藏·透明度三态测试，B0/B1 的联动判据），**这些测试从不测量"元素是否帮助用户理解、是否分散注意力"**。因此速度线/星点/点云/联动反馈等应标为 **【待验证设计】**，而非"已证明有效"：
- 保留的理由仅是"它们是实验装置、删了实验失去被研究的变量"，**不是**"它们已通过用户实验证明有益"。
- 取舍必须靠真人指标决定：任务完成时间、误操作率、理解准确率（见 M-EXPERIMENT / M3-ACCEPTANCE 的真人协议）——当前这些全部【真人】待验。
- 装置层"测试通过"只证机制在、判据可复算，绝不证"用户体验更好"。这是项目一贯的【装置层≠假设层】纪律，本清单初版违反，此处更正。

## 审查框架（四条原则）

1. **用户是人、带着问题来、要快速解决** — 北极星 = 问题是否被快速清晰解决（P0 结果可用性）
2. **关注的点必须清晰、不模棱两可** — 模糊文案与模糊编码都是负债
3. **图像与文字等视觉信号同等重要** — 两者都要清楚，且协同而非互相打架
4. **注意力不能被干扰、打乱** — 常驻触点、持续动画、重复信息都是干扰源

## 一句话结论

主轴信息本身是真实的（分叉树/路牌/结果牌/指纹环都由后端真实字段驱动，来源有诚实标注）。问题不在"信息不够"，而在三处叠加：**无信息的氛围层占据最大画面面积**、**同一信息被 3D+多个 2D 面板反复编码**、**v0.9.53 漏删的两处持续呼吸动效**。
